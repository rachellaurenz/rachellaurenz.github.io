Project Proposal
1.

This is a drawing pad that projects what you are drawing in real time. This would be good for playing drawing games where mutiple people have to see what one person is drawing.



2.



This is a little game. There is a joystick and arrow keys to move. You can switch the game with one of the buttons in the middle, the other little button turn the game on and off. The game is in an old box found at a thrift store.



3.



This little device is perfect for going on walks. There is a clock and compass so you do not get lost or lose track of time. If you think of something you want to write down, use the tool under the screen as a pen to take notes.



4.



Fruit Synth is a fun way to make music! You plug in the fruit on the right and use the keys on the left to make sound. The buttons in the middle change the octive, pitch, and other cool things!



5.



This is perfect for those bright cold winter days. It is a scarf that uses solar electricity to heat up like a heater blanket.
